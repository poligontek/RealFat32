# RealFat32 — Changelog

Creada por Fabian Gonzalez Dev · PoligonTek

## 0.3.0-alpha.1 — 2026-11-20

- Fondo claro más luminoso; se conserva el modo nocturno opcional.
- Idioma automático de Windows (español, inglés o portugués; inglés para otros idiomas) y selección manual opcional.
- Búsqueda de actualizaciones al iniciar y mediante botón, usando Releases de `poligontek/RealFat32`.
- Aviso Sí/No solo cuando hay una versión más reciente compatible con el canal elegido.
- Descarga con verificación SHA256, reemplazo automático, respaldo de la versión anterior y reinicio.
- Canales Estable, Beta y Alpha; versiones ordenadas como alpha < beta < rc < estable.
- Acerca de con créditos y este historial dentro de la aplicación.

## 0.2.0 — Preview — 2026-11-20

- Tema claro de Windows y modo nocturno.
- Español, inglés y portugués.
- Confirmación con cuenta atrás de tres segundos.
- Corneta, confetis y OK verde al completar el formato.

## 0.1.0 — Preview — 2026-11-20

- Primera implementación portable de Windows Forms y motor FAT32.
- Consulta de volúmenes, protecciones y pruebas en imágenes sintéticas.

Alpha: desarrollo y validación inicial. Beta: pruebas previas a una versión final. RC: candidata final. Estable: versión final publicada. Las versiones 0.1/0.2 fueron compilaciones locales preliminares, no publicaciones estables.
